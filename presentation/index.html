05The solution · architecture
Why that seam, and not a smarter prompt

No model output is ever a price.

  • Models emit structured evidence — a coverage probability, a price band, and the policy clause quoted verbatim.
  • Deterministic code turns evidence into a posterior, and the posterior into (a, b).
  • A prompt that emits a number cannot be swept, folded or replayed. A prompt that emits evidence can — pricing becomes a pure function we re-run over the entire record in a minute.
  • Every constant in the engine is a hypothesis with a falsifier written next to it.

And it means there is something underneath.

Games 82–89, all triple-weighted model endpoint → 401 on every call model_draws = 0 blind floor posted at T+0 Price Memory priced what it knew fitted constants covered the rest banked anyway: +254,092 weighted

We did not notice until afterwards. That is the point: the architecture degrades instead of failing.

06The solution · the arithmetic
Every scored number, in four steps — one module, no model in sight
1 BLEND — two model draws + the Price Memory anchor, inverse-variance, log space log m = Σ wᵢ·log mᵢ / Σ wᵢ w = 1/σᵢ² σ_mem 0.43 · σ_model 0.60 2 POSTERIOR — coverage is not a branch, it is probability mass at zero P(t) = (1 − p)·δ(0) + p·LogNormal(log m, σ) σ = log(hi/lo) / (2·1.645) 3 CHARGE — maximise k·P(t ≥ k·m). Falls with the error, never approaches 1. a = k(σ) · m k = clamp(0.85 − 0.45·σ, 0.30, 0.80) 4 LIMIT — accept iff a < 1.5a·P(fair), i.e. P(fair) > ⅔. So b is the ⅓ quantile. b = Q⅓(P) → if p ≤ ⅔ the bottom third is the spike at zero, so b = 0 by itself then b = min(b, ceiling·m) ceiling 1.00 memory-backed · 0.45 model-only

The ⅓ is derived, not tuned: rejecting a fair claim costs 1.5a, rejecting a fraudulent one costs nothing, so the indifference point is exactly two-thirds. Four separate attacks on it were measured and lost.

11The proof
The one we shipped and took back out — 20 minutes, in the last hour

It passed every test we had.

  • A genuine calibration table: items stated 0.20–0.40 were 62 % covered, items stated 0.60–0.80 were 93 %.
  • Positive on all four folds, no negative cell in any window. +5,057.

Then we checked the mechanism.

  • The model's coverage output is bimodal — it says 0.01, or it says 0.9.
  • An item must already sit in (0.560, 0.667] for the correction to change anything. 4 of 573 do.

The +5,057 was not the documented mechanism at all — it was the same exponent nudging the Limit up on the 333 confident items. A Limit raise wearing a calibration costume.

Two lessons. A constant can be right about its data and wrong about its mechanism. And the four-fold bar has a hole: folds catch a result driven by a few Games, never one driven by a few items.

12The proof · discipline
Two traps that each cost a full working session

1. Conditioning on the outcome

Bucket items by what they turned out to be worth and strictness pays 9.9 : 1 under €100 and loses above €500 — a compelling case for raising the Limit on expensive items.

Bucket by t̂, the only split knowable at submission time, and the gradient collapses. Of 23 items we believed were worth over 2,000, 14 turned out to be worth under half that.

Every rule built on the first table loses money. Never condition on the answer.

2. Censoring

44 of 192 items have no upper bracket. An interval is unbounded precisely because nobody rightfully rejected — which correlates with the item being expensive.

So any statistic conditioned on "censored" is selection on the answer, and every σ we quote is optimistic. We say so rather than quoting the flattering number.

Same discipline killed a tempting story: the 8 dark Games look like proof the model channel is dead weight (28.4 % capture dark vs 17.5 % live). A permutation test over 200,000 shuffles returns p = 0.208. "Measurably better channel" and "switch the other one off" are different claims, and only the first is evidenced.

15Close
What we would build next, in order — and what we deliberately did not
  • Clause 7.1.5, the half the model does not read. Indemnity is confined to the affected parts, but "where an affected room was wetted as a whole, the whole of that room is treated as affected". The model reads only the first half. Game 74 returned coverage 0.01–0.05 on 20 of 31 Line Items for €41,710 — 87 % of that Game's penalties.
  • We diagnosed it and did not ship it. Perfect coverage is worth +1,173 per Game, but it is a prompt change, it could not be validated without spending the live runner's quota, and it would have landed six Games before the 3× window with no way to tell a fix from a regression. That call is in the write-up, not hidden.
  • Carry an invoice id per Line Item — turns a leaky ordinal heuristic into a deterministic rule.
  • Calibrate the band. The model asserts a median σ of 0.375 against a realised error near 1.0, and the asserted width does not even order the realised error.

Every number in this deck is reproducible from a script in the repository. No claim data is checked in — not the Cases, not the invoices, and not the four derived paths that would reproduce them.
